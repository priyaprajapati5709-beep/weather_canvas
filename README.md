# Weather Canvas Application

## Project Overview

Weather Canvas is a JavaScript weather forecast application that provides current weather conditions and a 5-day forecast using OpenWeather API.

## Features

• Search weather by city  
• Current location weather  
• 5 day forecast  
• Temperature toggle (°C / °F)  
• Recent search dropdown  
• Weather icons  
• Dynamic backgrounds  
• Extreme weather alerts  
• Responsive design  

## Technologies Used

HTML  
Tailwind CSS  
JavaScript  
OpenWeather API  
LocalStorage  
Geolocation API  

## Setup Instructions

1 Download project

2 Open index.html

3 Insert your API key inside script.js

4 Run using Live Server
